# PHALANX DATAPACK
minecraft Javaで使える, 重力＋空気抵抗補正,偏差射撃などを備えた高機能ファランクスのデータパックです。

## 特徴
外観はシンプルめ、標的に向けて矢を発射します。
- 偏差射撃　動いている標的が発射時の位置、速度のまま等速直線運動をした場合にちょうど命中するように射撃します。
- 重力＋空気抵抗補正　矢が重力、空気抵抗を受けて描く軌跡を計算に入れています。
- 標的の優先度　関数化し、ある程度複雑な設定ができます。距離や速度、必要な旋回量などの複数の指標を線形結合して決定する形です。重みパラメータを変えればどの指標をどの程度優先するか調節できます。

### 使い方
- 注意 問題なく使えるよう作ったつもりですが、ワールドに予期せぬ影響を与えるかもしれません。実行は自己責任でおねがいします。不具合が起きてもいいワールドで試すか、バックアップを取っておくことをお勧めします。特に私は今回初めての配布ですから、しっかりと自分のワールドを守ってください。

AppData/Roaming/.minecraft/saves/{ワールドの名前}/datapacks/(<--マイクラのワールド選択画面でワールドを選択した状態で「編集」ボタン-->「ワールドフォルダーを開く」で見つかるdatapacksフォルダ)
に、このphalanxフォルダをおけばワールドを起動するだけで動くと思います。

ワールド起動後、金床などでスライムボールに"phalanx"と名前を付け、好きな場所でshiftすればその場にファランクスが出現します。もう一つ出したければ、一回アイテムを持ち替えてから再度試してください。(何かのうっかりで事故りそうなためそのようにしています。)
初期設定では、矢やblock_display,防具立て,プレイヤー,村人などを標的候補から除外しています。何か変更が必要であれば、c_and_dファイル内に"#標的の種類の指定はここ"と示されたコマンドを変更してください。

### 各ファイルの役割
- a: ワールド読み込み時に一度だけ実行される。必要なスコアボードのオブジェクトを追加する。また、優先度関数の重みパラメータを定める。
- b:ファランクスを設置する関数。繰り返し実行される。
- c,c2,c3:ファランクスを動かす関数の旧バージョン。使いません。重力＋空気抵抗補正はありませんでした。
- c4-newton_method:ファランクスを動かす関数、繰り返し実行。このデタパの中核。原理の詳細はfunctionフォルダ内のREADMEを参照してください。
- exp: c4内の計算の途中で必要となる指数関数の評価。テーラー近似によって計算。
- c_and_d,2,3:標的の優先度を評価する。
